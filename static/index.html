Probability Axioms, Formulas & Proofs

Formal analytical derivations, moment generating functions, and operational identities.

Kolmogorov Probability Axioms

  • 1. Non-negativity: P(E) ≥ 0 for any event E ⊆ Ω
  • 2. Unitarity: P(Ω) = 1.0 (certainty of sample space)
  • 3. Countable Additivity: If E₁, E₂, ... are mutually disjoint, then P(∪ Eᵢ) = ∑ P(Eᵢ)

Central Limit Theorem (CLT)

Let X₁, X₂, ..., Xₙ be independent identically distributed (i.i.d.) random variables with finite expectation μ and variance σ². Then the normalized sample mean converges in distribution to standard normal:

Zₙ = (X̄ₙ - μ) / (σ / √n) ⎯⎯⎯→ N(0, 1) as n → ∞

Exponential Memoryless Property Proof

Theorem: For X ~ Exp(λ), P(X > s + t | X > s) = P(X > t).

P(X > s + t | X > s) = P(X > s + t ∩ X > s) / P(X > s)

= P(X > s + t) / P(X > s) = e^(-λ(s+t)) / e^(-λs) = e^(-λt) = P(X > t) ∎

Poisson Limit of Binomial

When n → ∞ and p → 0 such that λ = np remains constant:

lim (n choose k) p^k (1 - p)^(n - k)

= lim (n(n-1)...(n-k+1)/k!) · (λ/n)^k · (1 - λ/n)^(n - k)

= (λ^k / k!) · lim (1 - λ/n)^n · 1 = (λ^k · e^(-λ)) / k! ∎
